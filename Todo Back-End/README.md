# Project AirBNB (Minor)

A full-stack Airbnb-inspired web application built with **Node.js**, **Express.js**, and **MongoDB**. The project allows users to browse, create, edit, and manage property listings through a clean and responsive interface.

## Features

* User authentication and authorization
* Create, read, update, and delete (CRUD) listings
* Property details page
* Image upload support
* Secure route protection
* Server-side validation
* Flash messages for user feedback
* Error handling middleware
* Responsive user interface
* RESTful architecture

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/project-airbnb.git
```

Move into the project directory:

```bash
cd project-airbnb
```

Install dependencies:

```bash
npm install
```

Create a `.env` file and configure the required environment variables.

Start the development server:

```bash
npm run dev
```

Or start the application:

```bash
npm start
```

Open your browser and visit:

```
http://localhost:3000
```
